# 宮くみ 書院の見本（技術検証）

**『月蝕綺譚 -Luna Occulta-』の非公式二次創作『宮くみ』の技術検証用ページです。公式作品ではありません。遊ぶものではありません。**

Unity 6（WebGL・Built-in）で書院を 1 部屋だけ組み、ブラウザで次の 3 点を確かめます。

1. **重さ**: Brotli 圧縮＋ decompressionFallback（GitHub Pages は Content-Encoding を付けないため）。合計 約 7.9MB（2026-09-23 の軽量化で灯を焼き付けた分、ライトマップ 1 枚が増えた）
2. **公式ちび 3D の実行時取得**: 宵闇素材庫の配布元から栞のちび GLB（約 8.1MB）を実行時に取ります。**GLB はこのリポジトリにもビルドにも入っていません。**取れないときは仮の姿のまま続きます
3. **わいわい SDK のセーブ往復**: `sdk.js` の `save` / `load` だけを使います（番付は呼びません）。画面の隅に結果が出ます

検分用: `?chibi=bad`（取得の失敗を見る）／`?chibi=off`（取りにいかない）／`?dpr=1.5`（描く細かさを下げる）／`?msaa=off`（縁のなめらかしを切る）／`?post=off`（後処理を切る）

軽量化（2026-09-23）: 灯と影はライトマップに焼き付け（実行時の灯は 0）、部屋の部品は材質ごとに 1 つへまとめた。1 フレームの描画は 6,299 回 → 139 回、三角形は 232 万 → 15 万。
